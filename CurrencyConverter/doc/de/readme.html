Währungsrechner

Eine NVDA-Erweiterung, die entwickelt wurde, um Ihnen blitzschnelle Ergebnisse bei der Währungsumrechnung direkt bereitzustellen.

Autor: Mister Anas

Installation

Sie können diese Erweiterung direkt aus dem NVDA Add-on Store installieren oder das neueste Paket von der Releases-Seite herunterladen.

Bedienung

  • Dialog öffnen: Drücken Sie die Tastenkombination NVDA+Alt+C oder öffnen Sie das Menü Werkzeuge in NVDA und wählen Sie Currency Converter.
  • Umrechnen: Wählen Sie im Dialogfeld Ihre Ausgangs- und Zielwährungen aus den Kombinationsfeldern aus, geben Sie den gewünschten Wert in das Betragsfeld ein und aktivieren Sie die Schaltfläche Weiter (Next), um das Ergebnis sofort anzuzeigen.
  • Intelligentes Speichern: Die Erweiterung merkt sich automatisch die zuletzt verwendeten "Von"- und "Nach"-Währungen und stellt diese beim nächsten Aufruf direkt ein.

Hinweis zum Quellcode: Die zentrale Initialisierungsdatei (__init__.py) enthält älteren Code aus den frühen Entwicklungsphasen.
